# Авито → WooCommerce · GG

Плагин WordPress для подготовки и переноса собственных объявлений в WooCommerce и локальный браузерный помощник для Windows / Python.

**Версия 0.1:** импорт ZIP/CSV, предпросмотр, редактирование, массовая смена цены/категории, создание черновиков, публикация выбранных, обновление по ID Авито, экспорт ZIP с фотографиями, CSV, история и повтор ошибок. Внешний аккаунт для проверки панели не нужен: есть две демопозиции.

## Установка плагина

1. Скачайте готовый [avito-gg.zip](packages/avito-gg.zip) из этого репозитория (на странице файла → **Download raw file**).
2. В WordPress откройте **Плагины → Добавить плагин → Загрузить плагин**.
3. Загрузите именно `avito-gg.zip`, установите и активируйте. Архив всего репозитория для установки в WordPress не подходит.
4. Откройте **Авито · GG** в левом меню. Проверьте настройки и попробуйте демопозиции.

Требования: WordPress 6.5+, PHP 8.1+, активный совместимый WooCommerce; PHP ZipArchive для ZIP. Для временных загрузок нужен доступный PHP `sys_get_temp_dir()` вне каталога WordPress. Права пользователя: `manage_woocommerce`, для записи товаров `edit_products`, для публикации `publish_products`.

Готовый пакет также собирается в GitHub Actions → **Checks and plugin package** → артефакт `avito-gg-wordpress-plugin`. В нём лежит установочный ZIP.

## Как забрать объявления

1. На компьютере установите **Python 3.11+** с компонентом Tcl/Tk (он обычно включён в стандартный установщик Python для Windows).
2. Скачайте репозиторий целиком: **Code → Download ZIP**, распакуйте.
3. Запустите **Start_Helper.bat**. В первый раз он создаст `.venv`, установит Playwright и Chromium. Для этого нужен доступ к серверам загрузки зависимостей.
4. Нажмите **Открыть Авито / войти**. Войдите непосредственно на Авито в открывшемся браузере, при необходимости пройдите подтверждение вручную.
5. Вставьте HTTPS-ссылку на страницу **своих объявлений** / свой магазин. Укажите число страниц, лимит объявлений и паузу. Нажмите **Собрать объявления**.
6. Проверьте журнал. На вкладке **Проверка и ZIP** можно редактировать названия, цену, категорию, описание и характеристики. Фотографии будут доступны для предпросмотра после импорта в WordPress.
7. Выберите позиции или оставьте выбор пустым для всех. Нажмите **Сохранить ZIP**.
8. В WordPress → **Авито · GG → Подключение и загрузка** загрузите архив. Дождитесь обработки. При остановке или закрытии вкладки нажмите **Продолжить** в списке загрузок.
9. На вкладке **Товары** проверьте карточки, выберите нужные и нажмите **Создать / обновить черновики** либо **Опубликовать / обновить**.

Помощник **не подключается к WordPress автоматически**: файл переносится вручную. В админке WordPress нельзя открыть локальное окно входа Авито без запущенного помощника; в этой версии вход запускается кнопкой в самом помощнике. Сохранённая в WordPress ссылка служит справочной настройкой; в помощник её нужно вставить отдельно.

### Честно о сборе с Авито

Сборщик написан для структурированных данных JSON-LD и настраиваемых CSS-селекторов. **На реальном аккаунте Авито он пока не проверен.** Авито может менять разметку и ограничивать браузерную автоматизацию. При капче сбор останавливается, проверку проходит пользователь. Нет обхода капчи, прокси-ротации или обещания незаметного сбора.

Если ничего не найдено, проверьте страницу и селекторы на вкладке **Настройки разметки**. Поддерживается переход по ссылке следующей страницы (`href`); бесконечная прокрутка и кнопки без ссылки не реализованы. В таком случае запустите сбор с адреса следующей страницы. Каждый успешно прочитанный товар сохраняется отдельно, повторные ID пропускаются. Ошибочные карточки можно собрать повторно. Для повторного сбора уже сохранённой карточки уберите её из локального списка.

Сессия, настройки, карточки и фото хранятся в `helper/.local/`, исключены из Git. **Не отправляйте этот каталог другим людям:** профиль браузера содержит сессию аккаунта. Выход — кнопка **Удалить локальную сессию / выйти**; товары при этом сохраняются.

Ручной запуск на Linux/macOS:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r helper/requirements.txt
.venv/bin/python -m playwright install chromium
.venv/bin/python helper/app.py
```

Нужен графический сеанс и Tkinter. На Linux Chromium может потребовать системные зависимости.

## Правила импорта и обновления

- Загрузка создаёт **подготовленные позиции**, не товары на витрине.
- Ключ сопоставления — ID объявления Авито. Повторы в одном файле отклоняются.
- Повторная загрузка по умолчанию пропускает уже подготовленные позиции. Галочка **Заменить подготовленные данные** заменяет их, включая ручные правки. Товары сайта меняются только отдельным действием переноса.
- Для новых товаров переносятся все поддерживаемые поля. Для существующих — только отмеченные в настройках; по умолчанию **цена**.
- Наценка применяется каждый раз к цене источника, а не к уже изменённой цене сайта.
- Действие создания черновиков **сохраняет статус** уже существующего опубликованного товара; новые создаются черновиками.
- Точное совпадение названия категории источника с категорией WooCommerce назначает её; иначе используется категория по умолчанию. Для другого сопоставления измените категорию в подготовленной позиции. Автоматического создания категорий нет.
- Фото скачиваются в медиатеку, повторно используются по SHA-256. Ошибка фото оставляет позицию в ошибках задания; ранее скачанные изображения могут остаться в медиатеке и будут использованы при повторе.
- Отсутствующая цена допускается в подготовке; перенос в WooCommerce потребует указать цену.
- Временные задания и архивы очищаются по WP-Cron через семь дней. Сервер может очистить системный временный каталог раньше; тогда загрузите файл заново.

## Один файл и лимиты

Основной формат — **ZIP**: `products.json` в корне, изображения в `images/`. При фотографиях общим размером до 100 МБ помощник формирует один архив; большую выгрузку делит на части. Это помогает уложиться в лимиты хостинга. В настройках PHP лимиты `upload_max_filesize`, `post_max_size`, `memory_limit`, `max_execution_time` должны соответствовать размеру загрузки и времени обработки одной карточки с фото.

Плагин принимает до **5000 позиций**, ZIP/CSV до **128 МБ** (также действует меньший лимит PHP), распакованные данные до **512 МБ**, одно фото до **20 МБ**, до **30 фото** на карточку. Данные обрабатываются по одной позиции за запрос. Один запрос может загрузить все фото одной карточки; очень короткий PHP-таймаут потребует изменения настроек хостинга. Страница показывает ошибки и позволяет продолжить.

Экспорт плагина работает для выбранных позиций: до 200 за раз, до 64 МБ фото на ZIP. CSV содержит ссылки на медиа; ZIP содержит сами файлы. CSV экранирует потенциальные формулы Excel апострофом; для точного переноса туда-обратно используйте ZIP.

### Формат ZIP

```json
{
  "version": 1,
  "items": [
    {
      "avito_id": "1234567890",
      "title": "Кресло",
      "description": "Описание",
      "price": "12000.00",
      "category": "Мебель",
      "url": "https://www.avito.ru/...",
      "images": ["images/chair.jpg"],
      "attributes": {"Цвет": "Белый", "Состояние": "Новое"}
    }
  ]
}
```

Изображения: JPEG, PNG, WebP. Внутренние имена: `images/имя.jpg` из латинских букв, цифр, дефисов и подчёркиваний. Допускаются HTTPS-ссылки вместо файлов; хост источника должен разрешать загрузку. ZIP не распаковывается произвольно на сервер; читаются только manifest и конкретные файлы фото.

CSV: UTF-8, запятая, столбцы `avito_id,title,description,price,category,url,images,attributes`. `images` — HTTPS-ссылки через `|`, `attributes` — JSON объект. Обязательны `avito_id` и `title`. [Пример CSV](examples/products.csv).

## Что пока не реализовано

- Официальный API Авито и OAuth, серверное подключение аккаунта из WordPress.
- Работа по расписанию, прямое соединение помощника с WordPress.
- Автоматическая синхронизация остатков и снятых объявлений.
- Вариативные товары WooCommerce, автоматическое объединение разных объявлений в варианты.
- Редактор фотографий / изменение порядка галереи в панели подготовки.

Создаются **простые товары**. Существующие сторонние товары без связи по ID Авито не перезаписываются. При деактивации/удалении плагина созданные товары и фото сохраняются.

## Разработка и проверки

```bash
python -m unittest discover -s tests -v
php tests/bundle.php
node --check plugin/avito-gg/assets/admin.js
python scripts/build.py
```

Локально прошли проверки форматов, DOM-интерфейса и интеграционный сценарий на отдельной установке WordPress 7.1.4 / WooCommerce 11.2.1 с SQLite Database Integration. Сценарий включает черновик, публикацию, повторное обновление, сохранение ручных правок, ZIP, фото и повтор ошибок. Сбор реальных объявлений Авито пока не проверен.

`tests/wordpress.php` запускается командой `wp eval-file` в одноразовой тестовой установке WordPress с WooCommerce и активным плагином; **не запускайте его на рабочем сайте** — он создаёт демонстрационные товары и меняет настройки. GitHub Actions проверяет синтаксис, формат файлов и интеграцию на отдельной БД.

Структура: `plugin/avito-gg` — устанавливаемый плагин, `helper` — помощник, `tests` — проверки, `scripts/build.py` — сборка ZIP. Секретов и данных аккаунта в репозитории нет.
